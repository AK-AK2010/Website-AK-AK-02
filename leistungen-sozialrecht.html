Leistungen · Sozialrecht

Leistungen im:
Sozialrecht

Bitte beachten Sie, dass ich nicht in folgenden Bereichen tätig bin:
  • Grundsicherung für Arbeitsuchende (SGB II) [ehemals „Hartz 4“ / Bürgergeld]
  • Kinder- und Jugendhilfe (SGB VIII)
  • Gesetzliche Pflegeversicherung (SGB XI)
  • Sozialhilfe (SGB XII)
  • Kindergeld (BKGG / EStG)
  • Wohngeld (WoGG)

In folgenden ausgewählten Teilbereichen des Sozialrechts bin ich gerne für Sie tätig:

SGB IV – Gemeinsame Vorschriften

  • Scheinselbständigkeit
  • Statusfeststellungsverfahren / Anfrageverfahren (Einzugsstelle, Rentenversicherung / Familienangehörige, GmbH-Geschäftsführer)
  • Betriebsprüfung / Beitrags(nach)forderung / Säumniszuschläge / Verjährung / Haftung (Arbeitgeber / Geschäftsführer) / Stundung / Ratenzahlung
  • Geringfügige Beschäftigung
  • Sozialversicherungspflicht bei Gesellschaften

SGB III – Arbeitsförderung

  • Versicherungspflicht
  • Berufsausbildungsbeihilfe
  • Berufliche Weiterbildung
  • Gründungszuschuss
  • Kurzarbeitergeld
  • Übergangsgeld
  • Arbeitslosengeld
  • Insolvenzgeld
  • Meldepflichten

SGB V – Gesetzliche Krankenversicherung

  • Versicherungspflicht, Versicherungsfreiheit, Befreiung von der Versicherungspflicht
  • Wechsel / Rückkehr von privater Krankenversicherung zu gesetzlicher Krankenversicherung
  • Kostenerstattung
  • Krankenbehandlung (u.a. Heilmittel, Hilfsmittel, häusliche Krankenpflege, Krankenhausbehandlung, Leistungen zur medizinischen Rehabilitation)
  • Krankengeld
  • Zahnersatz
  • Fahrkosten

SGB VI – Gesetzliche Rentenversicherung

  • Versicherungspflicht (Beschäftigte, selbständig Tätige, sonstige Versicherte, auf Antrag)
  • Versicherungsfreiheit / Befreiung von der Versicherungspflicht / freiwillige Versicherung
  • Medizinische Rehabilitation / Kinderrehabilitation / Teilhabe am Arbeitsleben
  • Renten wegen Alters: Regelaltersrente, für schwerbehinderte Menschen, für langjährig Versicherte, für besonders langjährig Versicherte
  • Renten wegen verminderter Erwerbsfähigkeit: teilweise Erwerbsminderung, volle Erwerbsminderung, teilweise Erwerbsminderung bei Berufsunfähigkeit
  • Renten wegen Todes: Witwen-/Witwerrente, Waisenrente
  • Wartezeit / Beitragszeit / Kindererziehungszeit / Berücksichtigungszeit / Anrechnungszeit / Zurechnungszeit
  • Hinzuverdienst

SGB VII – Gesetzliche Unfallversicherung

  • Versicherung kraft Gesetzes / Satzung / Versicherungsfreiheit / freiwillige Versicherung
  • Arbeitsunfall / Berufskrankheit
  • Heilbehandlung / Teilhabe am Arbeitsleben
  • Verletzengeld / Verletzenrente / Leistungen an Hinterbliebene
  • Gefahrtarif / Gefahrklassen / Beitragsbescheid

SGB IX – Rehabilitation und Teilhabe von Menschen mit Behinderungen

  • Schwerbehinderung / Gleichstellung
  • Leistungen zur medizinischen Rehabilitation
  • Leistungen zur Teilhabe am Arbeitsleben

SGG – Sozialgerichtsgesetz

  • Sozialgerichtsverfahren: Sozialgerichte / Landessozialgerichte / Bundessozialgericht
  • Anfechtungsklage / Leistungsklage / Verpflichtungsklage / Feststellungsklage / Untätigkeitsklage / Fortsetzungsfeststellungsklage / Nichtigkeitsklage
  • Vorläufiger Rechtsschutz / Eilverfahren
  • Berufung / Revision / Beschwerde
  • Beweisaufnahme / medizinische Gutachten von Amts wegen / Antragsgutachten (§ 109 SGG)

Meine Dienstleistungen für Sie im Sozialrecht:

  • Außergerichtliche Beratung und Vertretung
  • Widerspruchsverfahren vor Behörden
  • Gerichtliche Vertretung vor den Sozial- und Landessozialgerichten und dem Bundessozialgericht (Hauptsacheverfahren – Einstweiliger Rechtsschutz / Rechtsmittelverfahren)
